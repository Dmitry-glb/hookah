# DimHookah — New Experience

Обновление от 5 ноября 2026 года.

## Интерфейс и совместимость

Главная: быстрый прогрев на 7 минут, рулетка, короткая запись и три последних
покура. Таймер вынесен на отдельный экран с паузой и остановкой; он открывается
при обычном возвращении в PWA. Явная команда Siri `?action=roulette` сохраняет
свой маршрут. Формы, история и каталог оформлены спокойнее; оригинальные фото
не изменяются. На мониторе каталог использует до шести колонок.

Сохранены `HookahDB` v2, store `sessions`, `hookah_sessions`,
`hookah_active_session`, коллекция, чаши, цены пачек, угли и импорт/экспорт.
Миграции с удалением данных нет. Добавлено необязательное `pausedAt`;
при продолжении сдвигаются временные метки, исключая паузу из длительности.
`experience.js` перемещает прежние элементы с прежними ID, основная логика
остаётся в `app.js`. Локальная работа не зависит от облака.

В короткой записи обязательна оценка; подробные поля раскрываются отдельно.
Пропущенное время хранится как 0, а не выдуманный час покура.

## Подключение Cloudflare

Worker уже развёрнут: **https://dimhookah-preheat.swenplay23.workers.dev**.

1. В приложении открыть шестерёнку → Cloudflare и Siri.
2. Адрес сервера уже подставлен.
3. В поле ключа вставить **значение `PREHEAT_TOKEN`** из локального
   `worker/.dev.vars` (без имени переменной и кавычек).
4. При желании включить синхронизацию истории и нажать «Подключить».
5. Для фоновых push нажать «Включить фоновые уведомления» и дать разрешение.

На iPhone нужна PWA на экране «Домой». Разрешение уведомлений требует нажатия
самого пользователя. `worker/.dev.vars` игнорируется Git и не кешируется PWA;
ключи отсутствуют в публичных JS. Введённый ключ хранится локально на устройстве.

Это личный Worker: один ключ — один владелец и его устройства. Не раздавайте
его независимым пользователям. Другие посетители без ключа работают локально.

## Сервер

SQLite-backed Durable Object хранит таймер с абсолютным дедлайном, историю,
до 200 событий, до 10 push-подписок. Класс `PreheatCoordinator`, migration `v1`
и старые пути Siri сохранены. Новому деплою KV не нужен; прежнее состояние
читается из KV при наличии старого binding.

Alarm срабатывает к дедлайну без открытого браузера, снимается при паузе и
остановке, переносится при продолжении. Для покура есть напоминания на 60 и 90
минут. Нет ежесекундных сетевых запросов и постоянно работающего сокета.
При конфликте ревизий локальный таймер сохраняется; выбор серверного состояния
требует явного нажатия. Ошибки сети не останавливают локальную сессию.

История передаётся только после включения синхронизации. Изменения и удаления
идут через устойчивую очередь `hookah_cloud_queue_v1`, пакетами до 100 действий.
Повторные запросы имеют идентификаторы для защиты от дубликатов. После
возвращения сети очередь отправляется автоматически. Сохраняется до 2000
записей вместе с отметками удаления; превышение не удаляет локальные записи.
Для архива доступен прежний JSON-экспорт. Правки одного ID сервер принимает
в порядке поступления; это не система коллективного редактирования.

Приватные `/v1/state`, `/v1/timer`, `/v1/history`, `/v1/push` требуют Bearer.
Старый `/preheat/status` раскрывает только базовые параметры прогрева, без
истории и личных данных. CORS разрешает origin приложения и локальный preview.

## Бесплатный тариф и ограничения

Используется SQLite-backed Durable Object, доступный на Workers Free.
По официальной документации на дату проверки: 100 000 запросов DO/сутки,
13 000 GB-s/сутки, 5 млн строк чтения/сутки, 100 000 строк записи/сутки,
5 ГБ хранения на аккаунт. Квоты общие с другими приложениями аккаунта.
Платный тариф для этого решения не включался.

Push не является системным будильником iPhone. ОС, разрешения, сеть и push-сервис
могут задерживать доставку. Серверный Alarm не гарантирует показ на телефоне
ровно в секунду. При открытии PWA восстанавливается реальное время по меткам.

Источники:
- https://developers.cloudflare.com/durable-objects/platform/pricing/
- https://developers.cloudflare.com/durable-objects/api/alarms/
- https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/

## Развёртывание и проверка

`npm run worker:setup` генерирует отсутствующие ключи, сохраняет их в
игнорируемый `.dev.vars`, развёртывает код и передаёт секреты через stdin.
Другой origin: `npm run worker:setup -- https://example.com`.
`npm run worker:deploy` обновляет код, сохраняя секреты и данные DO.
`npm run worker:check` проверяет сборку без публикации.

Проверены прежние сценарии Siri, пауза/reload, короткая запись, история,
офлайн-очередь, ревизии, шифрование Web Push и удаление истёкших подписок.
На реальном Worker сработал тестовый 6-секундный Alarm; затем он остановлен,
история пользователей не менялась. Доставка на физический iPhone потребует
подключения устройства и разрешения. Эти действия нельзя подтвердить тестом
без подписки самого телефона.
