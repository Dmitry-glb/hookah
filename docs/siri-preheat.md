# Siri и Cloudflare — New Experience

Worker: `https://dimhookah-preheat.swenplay23.workers.dev`.
Полная инструкция: [облако, уведомления и ограничения](new-experience.md).

## «Запусти прогрев» в Shortcuts

1. URL: `https://dimhookah-preheat.swenplay23.workers.dev/preheat/start`.
2. «Получить содержимое URL»: POST, заголовок
   `Authorization: Bearer YOUR_KEY`. YOUR_KEY — значение `PREHEAT_TOKEN`
   из локального `worker/.dev.vars`.
3. Для показа таймера открыть URL приложения с `?action=preheat`.

Повторный POST активного прогрева возвращает тот же таймер.
GET `/preheat/status` сохраняет контракт:

```json
{"active":true,"startedAt":1793820000000,"duration":420,"remainingSeconds":300}
```

Этот старый endpoint отдаёт только параметры времени; история, чаша, табак,
журнал и подписки доступны через защищённые API.

## PWA

В настройках приложения указать Worker и тот же ключ. Для старой односторонней
интеграции можно по-прежнему заполнить `apiBaseUrl` в `lib/preheat-config.js`:
GET выполняется при запуске/возврате, без ежесекундного polling. Активная
локальная сессия автоматически не заменяется импортированным прогревом Siri.

`cloudApiBaseUrl` только подставляет адрес в настройки. Ключа в публичном JS
нет. Другие посетители сайта без подключения работают локально.

- `?action=preheat` — локальный запуск с последним выбранным временем
  прогрева (7 минут по умолчанию). Если сессия уже идёт, повторного старта и списания углей нет.
- `?action=roulette` — открыть рулетку с сохранением активной сессии.
- Обработанный `action` удаляется из URL; прочие параметры сохраняются.
- Обычное возвращение в PWA открывает отдельный экран активного таймера.

SQLite-backed Durable Object поддерживает паузу, остановку, историю и Web Push.
Создавать KV namespace для нового деплоя не нужно. Имя Worker, класс,
binding и migration v1 сохранены; при наличии старого PREHEAT_KV binding
предусмотрено чтение его состояния. Токен Siri остаётся PREHEAT_TOKEN.

Локальные данные, коллекция и IndexedDB продолжают работать без сети.
Cloudflare не управляет «Часами» iPhone. Для фоновых уведомлений нужна
подписка PWA и разрешение пользователя на самом устройстве.
